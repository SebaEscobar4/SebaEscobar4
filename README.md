## Proyectos destacados

### [CompliSec](https://github.com/SebaEscobar4/CompliSec)

Prototipo académico colaborativo para apoyar la gestión de riesgos, controles, evidencias y auditorías basadas en ISO/IEC 27001:2022. Integra un frontend en React, una API BFF en Node.js y una base de datos PostgreSQL, con ejecución mediante Docker y verificación continua en GitHub Actions.

### [POS Minimarket](https://github.com/SebaEscobar4/pos-minimarket)

Sistema de punto de venta e inventario para un minimarket: ventas, caja, inventario trazable, reportes y auditoría. Monolito modular con backend en Java 21 y Spring Boot, frontend en React con TypeScript y base de datos PostgreSQL, con migraciones Flyway, pruebas automatizadas y verificación continua en GitHub Actions.
